Built a simulated IT Help Desk workflow using Jira Service Management to practice ticket intake, investigation, troubleshooting, documentation, resolution, and verification.

TEC-1 — Active Directory Account Lockout

Problem: User was unable to log in to Windows.

Investigation: Verified the user's Active Directory account and confirmed that the account was locked.

Resolution: Unlocked the user's Active Directory account.

Verification: User successfully logged in to the Windows client.

Documentation: Recorded the troubleshooting and resolution in Jira Service Management.

TEC-2 — Active Directory Password Reset

Problem: User was unable to log in because they forgot their Windows password.

Investigation: Verified the user's Active Directory account and confirmed that the account was not disabled or locked.

Resolution: Reset the user's password and required a password change at next logon.

Verification: User successfully authenticated to the Windows client and completed the password change.

Documentation: Recorded the troubleshooting and resolution in Jira Service Management.
